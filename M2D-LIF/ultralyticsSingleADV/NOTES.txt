三、运行方法
================================================================================

1. 基本用法
--------------------------------------------------------------------------------
# 训练 IR 单模态
cd /mnt/home/pyq_code/ADV/M2D-LIF
python train_single_adv.py --data teacherTraining/FLIR_IR.yaml --epochs 100

# 训练 RGB 单模态
python train_single_adv.py --data teacherTraining/FLIR_RGB.yaml --epochs 100

2. 自定义对抗参数
--------------------------------------------------------------------------------
python train_single_adv.py \
    --data teacherTraining/FLIR_IR.yaml \
    --epochs 100 \
    --batch 16 \
    --device 0 \
    --epsilon-max 0.05 \
    --early-layer-idx 2

3. 禁用对抗训练（使用标准训练）
--------------------------------------------------------------------------------
python train_single_adv.py --data teacherTraining/FLIR_IR.yaml --no-adv

4. Python 代码调用
--------------------------------------------------------------------------------
from ultralytics.models.yolo.detect.train_adv import SingleModalADVTrainer

args = {
    'data': 'teacherTraining/FLIR_IR.yaml',
    'model': 'yolov8s.yaml',
    'epochs': 100,
    'batch': 16,
    'device': 0,
    # 对抗训练参数
    'adv_enabled': True,
    'epsilon_max': 0.05,
    'early_layer_idx': 2,
}

trainer = SingleModalADVTrainer(overrides=args)
trainer.train()


================================================================================
四、参数说明
================================================================================

参数                    默认值      说明
--------------------------------------------------------------------------------
--epsilon-max           0.05       最大噪声强度
--early-layer-idx       2          噪声注入位置（backbone 第几层）
--warmup-epochs         5          Warmup 阶段轮数
--stage2-ratio          0.2        干净微调阶段占比（最后 20%）
--no-adv                -          禁用对抗训练


================================================================================
五、训练阶段说明
================================================================================

Epoch:  [0 ... 5 .................... 80 ... 100]
        │       │                     │       │
        │       │                     │       └─ Stage 2: 干净微调
        │       │                     │           epsilon = 0
        │       │                     │
        │       └─ Stage 1: 对抗训练
        │            epsilon: 0 → 0.05 (线性增长)
        │            两次前向传播
        │
        └─ Stage 0: Warmup
             epsilon = 0
             标准单次前向


================================================================================
六、关于单模态 Teacher 的思考（重要！）
================================================================================

1. 当前实现的问题
--------------------------------------------------------------------------------
当前实现是"无 Teacher"的单模态对抗训练：

    第一次前向（干净）:  特征 → 预测 → 检测损失 → 获取梯度
                                              ↓
                                    生成对抗噪声

    第二次前向（加噪）:  特征 + 噪声 → 预测 → 检测损失

问题：没有"正确特征"作为参考，模型只知道"加噪后检测损失高"，
     但不知道"干净特征应该是什么样"。

2. 与双模态对抗训练的对比
--------------------------------------------------------------------------------
双模态实现有 Teacher：

    Teacher（双模态融合模型，已训练好）
        ↓
    提供正确的融合特征作为参考
        ↓
    蒸馏损失：让 Student 特征逼近 Teacher

单模态实现（当前）无 Teacher：

    没有参考，只有检测损失

3. 可能的后果
--------------------------------------------------------------------------------
- 模型可能只是"学会容忍噪声"，而不是"学会更好的特征表示"
- 效果可能有限，甚至可能降低性能
- 更像是"鲁棒性训练"，不是真正的"对抗学习"

4. 建议的改进方向
--------------------------------------------------------------------------------
方向 B：加同模态 Teacher（推荐）

    Teacher: 预训练好的 IR-only 模型（冻结）
    Student: 新的 IR 模型（加噪声训练）

    第一次前向:  干净特征 → Teacher特征（参考）
                          ↓
    第二次前向:  加噪特征 → Student特征
                          ↓
                 蒸馏损失：让 Student 特征逼近 Teacher
                 检测损失：保证检测能力

    这才是有意义的对抗训练：
    Teacher 告诉 Student "正确的特征应该长什么样"
    Student 在噪声干扰下学习逼近这个目标

5. 实现步骤（后续）
--------------------------------------------------------------------------------
(1) 先用 ultralyticsOri 训练一个单模态 Teacher
    例如：IR-only YOLOv8，在 FLIR_IR.yaml 上训练

(2) 修改 SingleModalADVTrainer，添加 Teacher 支持
    - 加载 Teacher 模型
    - 添加蒸馏损失（MSE 或其他）
    - 在第二次前向时计算蒸馏损失

(3) 训练流程：
    Stage 1: 干净前向 → 获取 Teacher 特征
    Stage 2: 加噪前向 → Student 特征逼近 Teacher
