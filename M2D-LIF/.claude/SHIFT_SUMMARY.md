# 💡 Shift 模块验证方案总结

## 🎯 核心思路

你需要验证**跨模态交互强制机制** (Shift Prediction) 是否能突破当前 0.441 的瓶颈。

基于与另一个 AI 的深度讨论，关键洞察是：
- **当前问题**: RGB+IR 直接相加没有提升，说明模型可能"偷懒"，没有充分利用两个模态
- **解决方案**: 通过强制模型预测平移量，让模型必须在两个模态中定位同一个物体，从而增强跨模态对齐

---

## 📊 4 阶段递进方案

### **第一阶段：最小可行方案（图像级全局平移）**
```
难度: ⭐⭐ | 耗时: 1-2天 | 预期收益: +0.005~+0.015 mAP
```

**实现逻辑**：
1. 对整张 RGB 图随机平移 (dx, dy)，IR 保持原样
2. 计算相对偏移 GT：`shift_gt = (dx_rgb - dx_ir) = (dx_rgb, 0)`
3. 模型同时预测：检测框 + 平移量 (dx, dy)
4. 损失：`L = L_det + 0.1 * L_shift`

**为什么能工作**：
- 模型必须同时在 RGB 和 IR 中找到同一目标才能正确预测平移量
- 单独用 RGB 或 IR 无法预测正确的相对偏移

---

### **第二阶段：渐进式学习（Dynamic Scheduling）**
```
难度: ⭐⭐ | 耗时: 3-5天 | 预期收益: +0.005~+0.010 mAP
```

**改进**：
- 前 20% epoch：关闭 shift，让模型学会基础检测
- 中间 60% epoch：逐步打开 shift（0% → 30%）
- 后 20% epoch：稳定阶段，最后 10 epoch 关闭 shift 进行蒸馏

**为什么更好**：
- 避免 shift 任务从一开始就压倒检测任务
- 符合课程学习理论
- 模型可逐步增强跨模态交互能力

---

### **第三阶段：特征级平移（关键突破点）**
```
难度: ⭐⭐⭐ | 耗时: 5-7天 | 预期收益: +0.010~+0.020 mAP
```

**核心创新**：从图像级平移 → 特征级平移

**为什么更强**：
```
图像级平移 (弱):
  - 空洞填充会产生人工伪影 (黑块、边界不自然)
  - 模型可能学会"找伪影"而不是真正的跨模态对比

特征级平移 (强):
  - 在特征图上做平移，无空洞问题
  - 操作的是高度抽象的"语义单元"，更能强制跨模态交互
  - 感受野内的特征包含更丰富的上下文信息
```

**实现要点**：
- 使用 RoI Align 从特征图中精准提取 BBox 对应区域
- 对特征块做空间偏移 (torch.roll / grid_sample)
- 拼回融合特征图
- 额外加入特征相似度损失：平移对齐后 RGB 和 IR 特征应接近

---

### **第四阶段：高级优化（冲刺 SOTA）**
```
难度: ⭐⭐⭐⭐ | 耗时: 7-10天 | 预期收益: +0.005~+0.015 mAP
```

**可选增强**：
- 目标级平移（平移单个 BBox 内的目标，不是整张图）
- 多尺度平移（在 FPN 多个层级应用）
- 自适应平移范围（根据目标大小调整）
- 融合策略优化（concat / add / attention 对比）

1. **理论基础**：基于自监督学习中的 pretext task 思想

3. **循序渐进**：从简单到复杂，降低失败风险
4. **特征级突破**：升级到特征级平移避免了像素级的伪影陷阱
